# Автоматическое решение курсов на сайте Stepik
Этот проект представляет собой простую автоматизированную систему для решения задач на сайте Stepik. В проект встроен решатель на базе OpenRouter API -  сервиса, предоставляющего бесплатные модели для использования.
## Установка
1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/mixadyt-star/AutoStepik.git
    cd AutoStepik
    ```
2.  Создайте и активируйте виртуальное окружение:
    ```bash
    python -m venv venv
    source venv/bin/activate
    ```
3.  Установите необходимые библиотеки:
    ```bash
    pip install -r requirements.txt
    ```
## Использование
### Конфигурирование
Для использования скрипта нужно настроить решатель и ввести данные аккаунта в файле main.py.
#### Настройка решателя
В конструкторе класса AiSolver в поля token и model вводим свой токен на сайте OpenRouter и используемую модель соответственно. Вот пример заполненного решателя:

    solver = AiSolver(
        ai_client=OpenRouterClient(
            token="sk-or-v1-fcbc04b76faa0...", # Можно завести на https://openrouter.io/keys
            model="xiaomi/mimo-v2-flash:free" # Список моделей можно найти здесь: https://openrouter.ai/models
        ),
    )
#### Настройка клиента
В конструкторе класса AutoStepik в поля email и password передайте свой логин и пароль от аккаунта на сайте Stepik.
Также можно выбрать количество параллельных процессов аргументом max_workers (не рекомендуется использовать больше 20 процессов). Вот пример заполненного клиента:

    AutoStepik(
        email="example@gmail.com",
        password="ExamplePassword123!!",
        solver=solver,
        max_workers=10,
    ).solve()
    
### Запуск скрипта
Чтобы запустить процесс автоматического решения задач, нужно выполнить команду:

    python main.py
    
В ходе работы программа попросит выбрать курс, который она будет решать. Выбор осуществляется вводом цифры соответствующего курса. Вот пример меню выбора:

    Choose course: 
        1. "Поколение Python": курс для начинающих
    AutoStepik > 1
